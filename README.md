# Our First Christmas Together — Storybook Edition

An intimate, mobile-friendly Christmas storybook for Rusty & Ica.

Pages:
- `index.html`: black and gold Christmas title page
- `menu.html`: a complete five-course Christmas menu and four drinks, each with a direct recipe link
- `letter.html`: personal photos and a short letter
- `recipes.html`: detailed food and drink recipes

Design: elegant gold particles, page-turn transitions, subtle botanical print details, mobile swipe navigation, reduced-motion support. No shopping list.

All 12 food and drink photos use the original HD WebP assets at 1448 × 1086. Photos and source code are public because the repository is public.

Launch: open `index.html` or deploy this folder to a static web host. No build step is required.
