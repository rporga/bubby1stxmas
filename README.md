# Our First Christmas Together

A private-in-spirit, static Christmas microsite created for Rusty and Ica, Christmas 2026.

## Features

- Mobile-first, cinematic homepage with original photography
- Five-course Christmas dinner menu and the three sides
- Four Christmas drinks
- Interactive recipe detail accordions, deep links, filters, and ingredient checkboxes
- Browser-persistent shopping checklist, copy list button
- Photo gallery lightbox, swipeable drinks, responsive mobile navigation
- Smooth scroll, editorial transitions and reduced-motion accessibility

## Getting started

Open `index.html` in a browser, or serve this folder with a static server (such as `python3 -m http.server 8000`). No build tools needed.

## Deploying

Use any static host, such as GitHub Pages or Vercel. Public repositories and public deployments expose photographs publicly; change repository visibility or use access protection if that is not intended. `noindex` is set on both pages to discourage search-engine indexing but **does not** make them private.

## Contents

- `index.html`: homepage, menu, drinks, photo gallery
- `recipes.html`: cooking plan, recipe details, interactive grocery list
- `assets/site.css`: styling, responsive layouts and animations
- `assets/site.js`: interactivity and local checklist saving
- `assets/photos/`: original couple photos (optimised WebP)
- `assets/food/`: food photos and menu illustrations from the previous website

## Notes

This site is inspired by the editorial restraint and immersive interaction of contemporary restaurant websites. It does not copy their code or trade dress.


## High-definition Christmas photography

The menu, sides, and cocktails use full-resolution 1448 × 1086 pixel generated food photography. These are encoded as quality-96 WebP **without resizing** for fast mobile delivery while preserving detailed, high-definition visuals. The illustrated placeholders have been replaced throughout both pages, including the ham feature and all three sides. The Christmas logo is the 2172 × 724 transparent original PNG (`assets/logo.png`).
